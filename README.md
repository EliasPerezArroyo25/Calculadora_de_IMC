# Calculadora de IMC

Al introducir el peso,altura y pulsar "Calcular" se obtiene el valor numérico del Índice de Masa Corporal (IMC) y la clasificación de la OMS siguiendo sus reglas: 

- < 18.5: "Bajo Peso"
- 18.5 – 24.9: "Peso Normal"
- 25.0 – 29.9: "Sobrepeso"
- ≥ 30.0: "Obesidad"
